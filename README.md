# ETERNAL — TRIPLE SEVEN AUDIO

Optical-inspired compressor and sustain effect, built with JUCE 8.

## Build

The repository includes a GitHub Actions workflow that builds macOS AU/VST3/Standalone and Windows VST3/Standalone using hosted runners. Open **Actions → Build ETERNAL → Run workflow**, then download artifacts from the successful workflow run.

This is an original optical-inspired model, not a circuit-accurate or officially affiliated Pigtronix product. Do not distribute as a verified analog emulation without hardware measurement and listening tests.

The source-only starter ZIP from the original conversation includes additional artwork. This repository uses a vector-drawn faceplate to remain buildable without binary art assets.
